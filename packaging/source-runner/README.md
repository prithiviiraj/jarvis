Local camera/app foundation: optional camera dependency install via ENABLE-CAMERA-DEPS.cmd (source-only, not binary redistribution clearance). Camera controls and foreground app tracking are OFF on launch. Window title tracking is a separate opt-in. Visible topmost sensing indicator, one-click OFF, Pause all and close stop/clear. No cloud upload, frame/video retention, automatic model calls or speech. See docs/local-awareness-acceptance.md. Physical webcam accuracy, sleep/resume and 24/7 soak are not proved by CI.
